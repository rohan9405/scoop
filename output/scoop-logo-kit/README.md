# Scoop logo kit

Four matching compositions: compact S mark, full SCOOP wordmark, horizontal lockup, stacked lockup. White, dark and mint transparent PNGs, plus white/mint accents.

- Large PNGs: mark 2048px, wordmark/horizontal 3200px wide, stacked 2400px wide.
- Small marks: 32, 64, 128, 256 and 512px.
- SVGs are editable vector masters; all letterforms are paths, with no font dependencies.
- White versions are meant for dark backgrounds. Dark versions are meant for light backgrounds.
- Preview sheet is an opaque presentation board. Individual PNGs have real alpha transparency.
- New geometric lettering and S symbol inspired by the requested minimal performance-brand style. Existing app files and deployment were not modified.

Created deterministically as vector paths and rasterized with Sharp, extending the app's existing SVG logo system.
